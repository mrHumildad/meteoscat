# Noun Project Free Icon Attribution Quick-Reference & Skill Guide

When using free icons from **Noun Project**, proper attribution is required by their Creative Commons (CC BY 3.0) licensing terms. This guide provides exact placement rules, standard formats, and reusable code snippets across different media.

---

## 1. Quick Citation Format Rule

Every free icon must be credited using this core structure:

> **"[Icon Name]"** icon by **[Creator Name]** from **Noun Project**.

* **For Web / Digital Formats:** The **Icon Name** should link to the specific icon's URL on Noun Project, and **Noun Project** should link to `https://thenounproject.com`.

---

## 2. Citation Guidelines by Medium

| Medium | Recommended Placement | Example / Format |
| :--- | :--- | :--- |
| **Websites & Blogs** | • Bottom of the page / footer<br>• Image caption<br>• Dedicated **Credits** or **Attribution** page | HTML hyperlink snippet (see Section 3) |
| **Presentations (Slides)** | • Bottom corner of the specific slide<br>• Final **Credits / References** slide | `"Cloud" icon by Alex Smith from Noun Project.` |
| **Mobile Apps** | • **Settings > Credits / Licenses** section<br>• **About** screen | Plain text list or rendered links |
| **Print & PDFs** | • Page margin or image caption<br>• **References / Acknowledgments** section | `"Search" icon by J. Doe from Noun Project.` |
| **Video Content** | • Video description text box<br>• End credits sequence | Listed under a **Visual Assets / Icons** section |
| **Social Media Graphics** | • Post description / caption text<br>• Fine print on graphic (if clean layout allows) | Included in caption with tag/mention |

## 3. Reusable Code Snippets

### HTML Snippet (Standard Web)

```html
<p class="icon-attribution">
  <a href="https://thenounproject.com/browse/icons/term/tree/" target="_blank" rel="noopener">"Tree"</a> 
  icon by <strong>Creator Name</strong> from 
  <a href="https://thenounproject.com" target="_blank" rel="noopener">Noun Project</a>.
</p>
```

### Markdown Snippet (Documentation & Readmes)

```markdown
["Tree"](https://thenounproject.com/browse/icons/term/tree/) icon by Creator Name from [Noun Project](https://thenounproject.com).
```

### Combining Multiple Icons (Group Citation)

```markdown
Icons used: ["Tree"](https://thenounproject.com/term/tree) by Creator A, ["Search"](https://thenounproject.com/term/search) by Creator B, and ["User"](https://thenounproject.com/term/user) by Creator C from [Noun Project](https://thenounproject.com).
```

---

## 4. Key Licensing Rules to Remember

1. **When Attribution is Required:**
   * Any time you download an icon under the **Free** option (Creative Commons BY 3.0).
2. **When Attribution is NOT Required:**
   * If you purchase an individual **Royalty-Free license** for the icon.
   * If you have an active **NounPro / Noun Project Unlimited Subscription**.
3. **Modifications:**
   * You are allowed to recolor, resize, or alter the icon, but you must still provide full attribution as noted above.
